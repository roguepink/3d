# おへや3D

写真から部屋を3Dにして、カーテン・照明・床・壁紙を置きかえ、中を歩き回れるアプリ。
スマホのブラウザだけで動きます(インストール不要・ホーム画面に追加できる)。

公開先: https://roguepink.github.io/3d/

## できること
- 👣 部屋の中を歩き回る(左側で歩く・右側で見回す、PCは WASD とマウス、スマホの傾きでも)
- ＋ カーテン・レース・ロールスクリーン・ブラインド(横型/縦型)・シーリングライト・ペンダント・シャンデリア・ブラケット・ダウンライト・フロアランプ・ラグ・カウンター・机・テーブル・ソファ・ベッド・棚・テレビ・絵・鏡・時計・観葉植物 を置く
- 🧱 床(フローリング・タイル・クッションフロア・畳・カーペット…)・壁紙・天井を貼りかえる。見本帳の写真も貼れる
- 🎤 言葉で指示(「ここにカーテンをつけて」「床をフローリングに」「壁を白に」「夜にして」「窓をつけて」…)
- 📷 部屋の写真の壁の四隅を合わせて、本物の壁として貼る。動画から場面を切り出す。360°パノラマ
- 📐 間取り:部屋を足して、ドアでつないで、家全体を歩く
- 🌙 昼と夜の切りかえ。📸 画像にして LINE などで送る
- 🤖 (任意)Gemini の鍵を入れると、自由な言い方の指示と、写真から部屋の広さの読み取りができる

## しくみ
- `index.html` / `style.css` / `js/*.js`(ビルドなし、three.js は CDN から)
- 素材の画像は使わず、`js/textures.js` がその場で描く
- 保存はこの端末の中(IndexedDB)。写真はどこにも送らない(AIを使うときだけ Google へ)
- `_check/` は動作確認用(Git に入れない)

## 確かめ方(開発用)

```
cd ~/claude-work/3d && python3 -m http.server 8765
```
